# create-glazeen

Creates a new project from a [Glazeen](https://glazeen.ai) template:

```bash
npm create glazeen@latest my-app
pnpm create glazeen my-app
yarn create glazeen my-app
```

Options of `create` work too, e.g. `npm create glazeen@latest my-app -- -t my-org/my-templates`.

This package runs [`@glazeen/cli`](https://www.npmjs.com/package/@glazeen/cli) `create`. See its [documentation](https://github.com/Glazeen/cli#readme) for templates and options.
